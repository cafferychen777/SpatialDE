# Upstream provenance

`spatialde-modern` is an independently maintained fork of
[Teichlab/SpatialDE](https://github.com/Teichlab/SpatialDE).

The maintenance line was created from upstream commit
`77f9fa5910838f5ee4308b4334a2e6ce85d1748e`. The original authors retain
copyright in their work. Changes made in this fork are distributed under the
same MIT license found in [`LICENSE`](LICENSE).

The distribution name is intentionally different from `SpatialDE`. The Python
import package remains `SpatialDE` for API compatibility.
